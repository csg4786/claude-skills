# Changelog — prompt-master

Initial version. Produces exhaustive, general-purpose prompts for any AI/task, covering role, objective,
context, inputs, instructions, output format, constraints, examples, edge cases, and a quality
self-check. Asks clarifying questions before drafting (per user preference) and includes a coverage
checklist reference (`references/coverage_checklist.md`) for less-obvious angles to consider.
